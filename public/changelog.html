Changelog

Notable changes to the NessGate resolver and its specification, newest first. Specification stability guarantees live in the specification.

2026

v1.1.0 — Initial public release

  • The neutral resolver. GET /discover/{domain} reads whatever a domain publishes across the supported machine-discovery locations (ARD / ai-catalog.json, A2A agent card, llms.txt, RFC 9727 api-catalog, ai-info.json, OpenAPI, Open Resource Discovery, host-meta) and returns one normalized answer, with a link back to each source so an agent can read the domain directly. NessGate reads these; it does not define or replace them.
  • Embeddable library. A dependency-free resolver at /resolver.mjs and on npm as @nessgate/resolver, running in browsers, Node, Deno, Workers, and agent runtimes with no runtime dependency on nessgate.com. The same lookup is available as the discover_domain MCP tool at /mcp.
  • Open and neutral. Open specification, Apache-2.0 reference implementation, governed by the Charter: free forever, neutral, no accounts, no ranking, no lock-in, stores nothing.
