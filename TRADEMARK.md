# NessGate name and trademark policy

The NessGate **code** is open source under Apache-2.0: you may fork it, modify
it, run it, and build products on it without asking permission. The Apache-2.0
license does **not** grant rights to the NessGate name or logo (see LICENSE
§6), and this policy explains the intent.

The goal is simple: **keep the code maximally open while preventing confusion
about what is the official NessGate project.**

## You may, without permission
- Fork, modify, and run the code.
- State that your software is **"compatible with the NessGate Resolver
  Specification"** or **"built on NessGate"**, accurately and without implying
  endorsement.
- Use the name nominatively to refer to this project (e.g. in documentation,
  articles, comparisons).

## Please do not, without permission
- Present your fork, service, or product **as the official NessGate project**,
  or name it in a way likely to confuse users into thinking it is official
  (e.g. calling your service simply "NessGate").
- Use the NessGate name or logo as your own product/company brand, or in a way
  that suggests sponsorship or endorsement by the NessGate project.

## Specification vs. implementation
"NessGate Resolver Specification vX.Y" refers to the open specification (see
https://nessgate.com/spec). The reference implementation carries its own
software version. A conformant independent implementation may advertise the
**resolver-spec** version it supports; it should not claim to be the
**project**.

This is a common-law statement of intent, not a claim of registered
trademark. Questions: contact@nessgate.com.
