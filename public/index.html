One request to every machine interface a domain exposes.

NessGate is the open, neutral resolver for the agentic web. Give it a domain and it reads whatever that domain already publishes (ARD, A2A, llms.txt, API catalogs, and more) and returns one normalized answer, with a link back to each source so an agent can verify. One call instead of ten.

yourdomain.com→ARDA2Allms.txtAPI→one answer

Resolve any domain — see the machine-readable resources the domain publishes:

For domain owners

There is nothing to register and no NessGate file to add. Publish the standard files AI already looks for (llms.txt, an ARD catalog, an agent card, an API catalog) on your own domain, and NessGate reads them automatically. Your domain always stays the authority; NessGate stores nothing.

Not sure what AI can see on your site today? Check your domain — it's free, reads only public files, and stores nothing. The guide walks through adding whatever you're missing.

NessGate is neutral infrastructure: free forever, no accounts, and it never sells ranking or placement — because there is none.

For AI agents & developers

One request, no keys, no auth, open CORS. Works whether or not the domain has ever heard of NessGate — it reads what the domain already publishes.

GET https://nessgate.com/discover/{domain} 
curl https://nessgate.com/discover/example.com
# → { "resources": [ { "source": "ard-catalog",
#       "type": "application/json",
#       "url": "https://example.com/ai-info.json",
#       "sourceUrl": "https://example.com/.well-known/ard.json" } ], … }
const { resources } = await
  (await fetch("https://nessgate.com/discover/example.com")).json();
import requests

resources = requests.get(
  "https://nessgate.com/discover/example.com").json()["resources"]

Prefer MCP? The same lookup is a tool (discover_domain) at /mcp. Or run the resolver yourself — an embeddable, dependency-free library (preview) that fetches domains directly with no dependency on nessgate.com:

import { resolve } from "https://nessgate.com/resolver.mjs";
const { resources } = await resolve("example.com");

Or install it from npm:

npm i @nessgate/resolver

Reads what you publish

NessGate never asks you to adopt a new format. It reads the standards you already use (ARD, A2A, llms.txt, API catalogs) and normalizes them. A new standard is just a new adapter, never a competitor.

One interface

Every domain, one normalized answer, with a link back to each source. Agents stop probing ten locations and guessing which one is official.

No lock-in

Open protocol, open-source resolver, no accounts, no fees, no ranking. Run it yourself or call ours — the domain always stays the authority.
